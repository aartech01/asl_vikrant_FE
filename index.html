How to use this. Every rate, quantity, date and owner below is editable and saves automatically in this view. The cost model is built bottom-up from measured quantities off your drawing — no budget ceiling assumed. Default rates are indicative Indian market benchmarks for 2026 and must be replaced with actual vendor quotations before you commit money. Structural, electrical and fire designs need sign-off by a licensed engineer; this is a planning and control tool, not a design or a professional cost certificate.

Saving, sharing and carrying this forward

Where everything is stored now. Every change you make is saved automatically to a shared database as you type, and every other team member's browser picks it up automatically within about 20 seconds. Photographs upload straight to permanent cloud storage the moment you add them. There is nothing to manually back up for the team to stay in sync — the buttons below are for taking an offline copy.
Autosave straight to a file on this computer
Link a .html file once and every change you make from then on — activities, BOQ, work items, anything — writes into that same file automatically, a second or two after you stop typing. No re-uploading, no remembering to click Download. Works in Chrome and Edge.
Share one file that already contains everything
Builds a fresh, standalone copy of the whole tool with today's data, and optionally your photographs, sealed inside it. Useful as an offline snapshot or an emailable copy — opening it does not reconnect it to the shared database.
